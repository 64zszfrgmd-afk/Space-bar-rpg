# Восстановление по доступной истории чата

Основа — опубликованная 0.20.0, main a446ad5 (владелец объединил PR №4). Работа продолжается в feature/restore-chat-history. Номер версии не меняется на 0.30; ревизия контента — history-2.

В доступном контексте есть ранние запросы пользователя, техническое задание и проверенный результат последнего восстановления. Нет полного содержимого всех старых ответов ассистента или исходного a8b5510. Поиск отсутствующего архива не повторялся. Поэтому этот документ отделяет сохранённые механики, восстановление по требованиям и будущие планы.

| Запрос из переписки | Реализация / состояние |
| --- | --- |
| Продолжать существующую игру, не создавать заново | Ветка от актуальной main; исходная сцена и старые системы сохранены; предыдущий ZIP остаётся отдельным неизменённым релизом |
| Боркс, семь напитков, бесплатная вода | Сохранена проверенная 0.20; Бип и его четыре рецепта также остались |
| Десять мест для сидения, энергия, встать | Сохранены все десять исходных мест; в новых интерьерах есть дополнительные сиденья |
| Зип у танцпола, его задания и отношения | Сохранены оба задания, валюты наград и старый прогресс |
| Новые игровые персонажи | Пять выбираемых видов, имя/цвет/аксессуар, отдельные 3D-модели четырёх вымышленных видов |
| Новые жители и инопланетяне | 23 NPC: прежние шесть, Лира, Грог, Мира-7 и 14 новых жителей; диалоги, настроение, симпатия и предпочтения |

Новые собственные названия:

- Станция «Последняя остановка»: «Пьяная туманность», «Нулевой меридиан», каюта.
- Карамель-9: «Ржавый спутник», «Комета навынос».
- Нереида: «Синий планктон», «Бездна 220».
- Люмен: «Тихая орбита», «Эхо пульсара».

Нельзя утверждать, что восстановлены все прежние точные тексты, модели, число NPC или квестов: соответствующих исходников в доступной истории нет. Новая реализация покрывает перечисленные запросы рабочими механиками; фактические результаты проверок фиксируются в PR и test-results/history-world.json.
