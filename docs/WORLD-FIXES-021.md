# Space Bar RPG 0.21.0 — мир, NPC и визуальная проверка

Основа — актуальная main `87e46aa` (0.20 R2). Ветка `feature/v0.21-world-fixes`. Сеть и новые игровые системы не добавлялись; исходные девять интерьеров, 23 NPC, пять героев и десять заданий сохранены.

## Подтверждённая причина

На портретном экране 390×844 камера 0.20 R2 использовала вертикальный FOV 62° и дистанцию шесть единиц как в альбомном режиме. Горизонтальный угол сужался примерно до 31°. В кадре оставались центр пола и герой, а стойки, мебель и почти все жители оказывались за краями. После перехода окружение действительно создавалось, но видимый участок казался прежним.

Это воспроизведено Chromium через реальные кнопки карты на baseline `87e46aa`. Для каждой модели сравнивался framebuffer WebGL с видимой и временно скрытой **только моделью** — без изменения именной подписи, камеры, освещения и других объектов. Все 14 жителей семи новых заведений давали **0 пикселей** при прибытии; в исходном баре отображались только Бип и Лира. Измерения и исходные снимки: [baseline.json](visual-v021/baseline.json), [Нулевой меридиан](visual-v021/v020-meridian-portrait.png), [Ржавый спутник](visual-v021/v020-rust-portrait.png). Доступ к renderer/scene добавлялся только в отдельной диагностической копии baseline.

Предыдущий автоматический тест подтверждал каталог, позиции и достижимость взаимодействий, но не проверял пиксели моделей. Поэтому его успешное выполнение не обнаружило проблему пользователя.

## Изменения

- Камера при прибытии показывает целый интерьер с расчётом по пропорциям экрана и размерам комнаты. Движение, жест обзора и переключение первого/третьего лица возвращают обычную камеру. В меню есть «Осмотреть зал».
- Меню «Найти жителей» поворачивает камеру к выбранному NPC. Оно не телепортирует игрока и не позволяет разговаривать на расстоянии; доступное взаимодействие появляется при подходе.
- NPC и подписи размещаются в отдельных группах своей локации. Активная группа включается вместе с соответствующим окружением; скрытый персонаж не даёт невидимое взаимодействие.
- Геометрия модели проверяется при создании; ошибка модели регистрируется и даёт видимый резервный прототип. Освещение, модели и мировые координаты проверены на изображении, а не только по имени в каталоге.
- Переход сначала строит и отрисовывает следующий интерьер, затем меняет состояние и освобождает предыдущий. При отказе построения/рендера прежняя сцена, её NPC, текущая локация и прогресс остаются доступными. Есть понятное сообщение и повтор загрузки в «Состоянии мира».
- Диагностика содержит версию, фактически отрисованную локацию, количество видимых моделей, ошибки загрузки NPC/подписей/локации и потери WebGL. Технические сообщения доступны отдельно от обычного игрового интерфейса.
- При освобождении новой комнаты также освобождаются instance buffers; общие источники света не размножаются. При загрузке сохранения непосредственно в другой интерьер исходный бар скрывается.
- Старый ключ localStorage `spacebar-restored-v020` сохраняется намеренно: сохранения 0.20 переносятся в 0.21 без сброса истории, валюты, отношений и заданий.

## Проверки и воспроизведение

```sh
npm install
npm test
SPACEBAR_BROWSERS=chromium npm run test:browser
# Для обоих движков с их системными зависимостями:
npx playwright install --with-deps chromium webkit
npm run test:browser
```

`tests/world-visual.mjs` проверяет production-переходы по всем девяти местам через touch-кнопки карты и перезагрузку сохранения. Затем opt-in dev-инструмент проверяет 9 реальных окружений, 23 модели NPC при прибытии, после наведения и крупным планом, доступный путь и диалог каждого жителя. Пять видов героя проверяются отдельными снимками и пиксельными масками: путешественник, кристаллид, мицелиец, орбион, лентокрыл. Сравнивается геометрия, а не только цвет/имя: девять окружений и пять героев должны иметь разные сигнатуры. Подписи остаются при скрытии модели, поэтому текст не может заменить проверку 3D.

Тест дополнительно вызывает отказ сборки сцены и проверяет сохранность предыдущего мира и валюты, затем успешное повторное путешествие. Старые сценарии `gameplay.mjs` и `history-world.mjs` проверяют напитки, сиденья, обе камеры, десять заданий, ритм, отношения, героя, настройки и сохранения. Unit-тесты покрывают rollback построения/отрисовки, старт с сохранённого мира и границы камеры для 320×568, 390×844, 360×800, 844×390.

В `test-results/world-visual/` формируются `results.json`, HTML-галереи, снимки девяти локаций, 23 NPC и пяти героев для каждого движка, а также три контактных листа. Actions сохраняет их в `mobile-launch-tests`. Preview Release дополнительно включает самостоятельный ZIP визуального отчёта и PNG контактных листов. Конкретный коммит и итоговые результаты указаны в PR. DEV-интерфейс изменения сцены отсутствует в production.

Физический iPhone и FPS на устройстве не измерялись. Проверки WebKit выполняются в Linux; они подтверждают движок и реальные кадры, но не заменяют Safari на конкретном телефоне. Если на iPhone останется сбой, меню «Состояние мира» покажет фактическую версию/локацию и зарегистрированную ошибку, что позволит отличить старый кеш от ошибки загрузки.

Публикация сайта — только из main после одобренного владельцем merge. ZIP предварительного выпуска не изменяет production Pages.
