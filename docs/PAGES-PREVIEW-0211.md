# Отдельный HTTPS-предпросмотр 0.21.1

Адрес после успешной публикации:
https://64zszfrgmd-afk.github.io/Space-bar-rpg/test/0.21.1/

Основной адрес https://64zszfrgmd-afk.github.io/Space-bar-rpg/ остаётся на 0.21.0.
GitHub Pages предоставляет один сайт на репозиторий. Интеграции запрещено создавать
новый репозиторий, поэтому тест размещается в отдельной подпапке существующего сайта.
При публикации сохраняется целиком исходный артефакт 0.21.0 из успешного запуска
42682075173, а не пересобранная копия. Шесть файлов проверяются по SHA-256 до и после
публикации. Их архив и манифест находятся в hosting/.

Запуск workflow_dispatch существующего deploy.yml из feature/v0.21-world-fixes:
publish_site_preview=true, publish_preview=false. Отдельная задача собирает
preview-dist с base=/Space-bar-rpg/test/0.21.1/ и VITE_SAVE_PREFIX=spacebar-test-0211:,
проверяет сборку и браузерный интерфейс, добавляет её к исходному артефакту и
публикует Pages. Коммит main должен совпадать с сохранённым манифестом, а текущие
файлы основного сайта — с архивом; иначе публикация прерывается. Деплой использует
отдельное окружение github-pages-test и общую очередь с production-деплоем.

Тестовые сохранения имеют отдельный префикс. Основное сохранение и его старый
резервный ключ не читаются и не перезаписываются тестовой версией. Новое
прохождение на тестовом адресе начинается отдельно. Без VITE_SAVE_PREFIX обычная
сборка использует прежние ключи, как раньше.

scripts/preview-pages-smoke.mjs проверяет настоящий собранный сайт локально и по
опубликованному HTTPS: скрипты/стили, 3D-запуск, отказ без пропуска, подход/диалог
Боркса, девять переходов с сохранением, диалог в другом баре, сохранность основного
ключа и восстановление тестового прогресса. Chromium и WebKit создают PNG и JSON
в test-results/pages-preview/. WebKit на Linux не заменяет физический iPhone.

PR №7 не объединяется; main и его исходники не изменяются. Если основной сайт
впоследствии обновится, для повторной публикации теста потребуется новый проверенный
артефакт и манифест: скрипт откажется возвращать сайт на устаревшую 0.21.0.
