# Проверки 0.20.0 / history-2

Ветка: feature/restore-chat-history. Основа: опубликованная main a446ad5, 0.20.0. Полный список требований и ограничения доказательств: RESTORE-HISTORY.md.

Окружение: Codex Cloud Linux, Node.js 24.22.1, npm 11.9.0; CI — Node.js 22, Chromium и WebKit.

- npm install: успешно, прежние зависимости сохранены, новых серверов и клиентских ключей нет.
- Vitest: 35 сценариев экономики, сохранений, старых заданий, нового сюжета, поручений, отношений, ритма и каталога. Старые schema 1 / spacebar-v1 переносятся без потери кредитов, знакомств, отношений и заданий.
- TypeScript strict / Vite: успешно. Base /Space-bar-rpg/, target Safari 15.4; Three.js отдельным локальным чанком, без CDN.
- Node production tests: пути JS/CSS, HTTP/MIME, trailing slash, version.json в project path.
- Mobile launch: WebGL, портрет/альбом 390×844 / 844×390, компактные 320×568 / 568×320 и Android-подобный 360×800; кнопки не перекрывают друг друга, задание ниже статистики, прокрутки нет. Ошибки JS/WebGL показывают понятное сообщение.
- Старый gameplay.mjs: производство — путь клавиатурой до Боркса, все семь напитков, отмена, точные эффекты, legacy-save и reload; dev — шесть рук, все десять первоначальных мест и безопасные выходы, оба задания Зипа без алкоголя, пауза и сброс touch-ввода.
- Новый history-world.mjs: production — все пять видов героя, аксессуар, танцевальный стиль, имя, громкость и графика сохраняются после перезагрузки. Production не содержит изменяющего сцену тестового интерфейса.
- Dev integration — обе ветки основного сюжета через игровые диалоги; карта до пропуска заблокирована; после открытия бесплатны все девять мест. Для каждого интерьера поиск по сетке коллизий подтверждает подход ко всем его NPC, сиденьям и выходу; посадка/вставание проверены в каждом месте. Местные задачи проходятся через интерфейс: ритм, катушка, межпланетные доставки, три раковины, отдых и загадка. Все семь наград выдаются один раз, алкоголь не требуется. Кровать, зеркало, последний мир и прогресс проверяются после reload.

Перемещение игрока в dev-тестах использует opt-in интерфейс с проверкой свободной позиции и предварительным поиском пути. Это интеграционные проверки геометрии и диалогов, а не утверждение, что каждый маршрут пройден вручную на телефоне. Производственная прогулка до Боркса использует настоящие клавиши. Multi-touch reset дополнительно проверяется синтетическими pointer events; настоящие нажатия кнопок — Playwright touch.

Итоговые результаты движков смотрите в Checks текущего PR и артефакте mobile-launch-tests: mobile-launch.json, gameplay.json, history-world.json и скриншоты. Локальный Chromium проверен; WebKit выполняется в GitHub Actions (локально не хватает GTK4/Graphene/Manette и других библиотек). WebKit Linux не заменяет физический iPhone. Android/физический Safari/FPS не измерялись.

Предпросмотр: работающий порт 5173, /Space-bar-rpg/. Постоянный ZIP создаётся из чистого коммита после успешной сборки; manifest содержит sourceCommit/revision и SHA-256 всех файлов. Старый preview.1 сохраняется; history-2 получает отдельный preview.2. main не объединяется автоматически.
