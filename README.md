# Пьяная туманность · Space Bar RPG 0.21.1

**0.21.1 · touch-flow-1**, исправление отображения миров и NPC поверх 0.20 R2. Сохранены девять настоящих интерьеров, 23 NPC, пять выбираемых видов, десять заданий и предыдущие сохранения. Подробная диагностика, все имена и методы визуальной проверки: [WORLD-FIXES-021.md](docs/WORLD-FIXES-021.md).

При прибытии показывается обзор всего зала с учётом пропорций экрана. Начни двигаться или проведи по сцене, чтобы вернуться к обычной камере. Меню → **Найти жителей** наводит камеру на NPC; подойди ближе для разговора. Меню → **Осмотреть зал** возвращает общий вид. При проблеме открой **Состояние мира**: там есть версия, фактически загруженное место и повтор загрузки.

## Проверка исправления на iPhone

Новая диагностика полного пути и пределы проверки описаны в [TOUCH-TRAVEL-0211.md](docs/TOUCH-TRAVEL-0211.md). Сверху игры постоянно отображается версия, сцена и состояние пропуска. Закрытый маршрут объясняет причину; найденный пропуск предъявляется в карте. «Найти жителей → Подойти» ведёт героя по настоящим проходам, после остановки нажми «Поговорить». В меню есть копирование диагностического отчёта и резервная копия прогресса.

Тестовый адрес GitHub Pages: **https://64zszfrgmd-afk.github.io/Space-bar-rpg/test/0.21.1/** (после успешного workflow публикации). Основной адрес остаётся на 0.21.0; его шесть файлов сохраняются без изменений. У теста отдельное сохранение. Схема публикации и проверки: [PAGES-PREVIEW-0211.md](docs/PAGES-PREVIEW-0211.md). Физический iPhone ещё требует повторной проверки: источник конкретного аппаратного сбоя без отчёта с устройства не установлен.

## Запуск

Node.js 22.12+ (проверено на 24):

```sh
npm install
npm run dev -- --port 5173
```

Откройте `http://localhost:5173/Space-bar-rpg/`. Production-сборка:

```sh
npm run build
npm run preview -- --port 5173
```

Сборка находится в `dist`. Её нужно обслуживать по HTTP(S) с префиксом **`/Space-bar-rpg/`**. Открытие index.html из приложения «Файлы» или предпросмотра ZIP не запускает игру. Все модели, текстуры и музыка создаются кодом; Three.js включён в сборку, загрузок с CDN нет.

## Предпросмотр на iPhone

Для тестирования опубликованной 0.21.1 открой в Safari **https://64zszfrgmd-afk.github.io/Space-bar-rpg/test/0.21.1/**. Сверху должна быть версия 0.21.1. Прогресс тестовой игры хранится отдельно от основной 0.21.0. Ports и работающая Cloud-среда для этого адреса не требуются.

Для локальной разработки через Codex Cloud:

1. Запустите указанный сервер в Codex Cloud.
2. Откройте **Ports / Предпросмотр → 5173 → Open in browser**.
3. Откройте полученную HTTPS-ссылку в Safari и добавьте `/Space-bar-rpg/` к её корню, если этого пути ещё нет. `localhost` на телефоне указывает на телефон, а не на облачную среду.
4. Для звука нажмите «Музыка». Для движения используйте джойстик слева; для обзора ведите пальцем по свободной части сцены. «Бег» удерживается одновременно с джойстиком.

Предпросмотр зависит от работающей среды. Постоянный сайт: **https://64zszfrgmd-afk.github.io/Space-bar-rpg/**. До объединения PR он продолжает показывать прежнюю main. В этой ветке production-публикация не выполняется.

## Сохранённое содержание 0.20 R2

Соответствие прежним запросам описано в [RESTORE-HISTORY.md](docs/RESTORE-HISTORY.md). Восстановлены категории функций из доступной переписки; новые названия и модели не выдаются за точную копию недоступного архива.

- **Девять локаций**: четыре бара, четыре клуба, каюта. Три планеты: Карамель-9, Нереида, Люмен; исходный бар остаётся на станции «Последняя остановка».
- **23 NPC**, в том числе Боркс, Зип, Лира, Капитан Грог, Мира-7 и жители четырёх фантастических видов. Каждый доступный персонаж имеет диалоги, знакомства, дружбу и сохраняемое настроение. Приглашения учитывают предпочтения и отказ; флирт требует симпатии.
- **Пять видов героя**: прежний путешественник, кристаллид, мицелиец, орбион, лентокрыл. Меню героя сохраняет имя, цвет, вид, танцевальное движение и аксессуар; вид меняет 3D-модель, прогресс общий.
- **Десять заданий**: прежние два Зипа, сюжет «Куда делся мой корабль?» с физическим/цифровым пропуском и семь поручений жителей. Доставка, сбор предметов, отдых, загадка и ритм-игра. Награды выдаются однократно.
- **Путешествия** открываются после сюжета: Боркс → Зип → Лира → подсказка → пропуск у дивана либо цифровая копия у Миры-7 → выход за DJ-пультом. Перелёты бесплатные. В каюте есть кровать и зеркало.
- **Танцы и ритм-игра**: три выбираемых движения (орбитальный шаг, шаффл, волна щупалец). на танцполе открой меню → «Ритм-игра». Нажимай пробел или «В такт» в момент «ЖМИ!». Восемь ударов; награда 20 кредитов за 600+ очков, максимум три оплаченных выступления за игровые сутки. Пауза останавливает счёт времени.
- **Настройки** качества и громкости сохраняются. Музыка по-прежнему включается только нажатием. Переходы выгружают геометрию предыдущей новой локации; динамические источники света не размножаются.

## Сохранённые механики 0.20

- Прежняя мультяшная 3D-сцена, ходьба/бег, столкновения, первая/третья камера, независимые указатели джойстика и обзора. Потеря фокуса сбрасывает управление.
- Шестирукий Боркс с движениями всех рук, подносом, шейкером и диалогами. Бип остался за стойкой с прежними четырьмя напитками.
- У Боркса семь напитков; отдельное подтверждение, отмена, проверка баланса и эффектов. Бесплатная вода и безалкогольная сингулярность позволяют играть без алкоголя.
- Десять интерактивных мест: четыре барных стула и два дивана по три места. Энергия восстанавливается при отдыхе; E / «Встать» возвращает в свободную точку. Камера работает сидя.
- Зип слева от танцпола, знакомства, дружба, ежедневные приветствия/угощения и личные истории. Игровые сутки — восемь минут активной игры. Дружеский подарок и награды выдаются однократно.
- Два восстановленных задания Зипа: «Разогрей вечеринку» (Зора, Квик, 15 секунд танца, 50 кредитов) и «Особый ингредиент» (ящик сиропа слева от стойки → Боркс → Зип, 85 кредитов).
- Настроение, энергия, опьянение, танцы, музыка, пауза и HUD с текущим заданием. Алкоголь для прохождения не требуется.
- Автосохранение раз в две секунды и после решений; кнопки сохранения/загрузки в меню. Старый ключ `spacebar-v1` читается, но не изменяется. Ключ — `spacebar-restored-v020`; schema 1 прежней 0.20 переносится в schema 2 с сохранением валюты, показателей, знакомств и заданий; ключ оригинальной недоступной игры `spacebar-save-v2` также не изменяется. При отключённом localStorage можно играть до закрытия вкладки.

ПК: **WASD / стрелки**, **Shift** — бег, перетаскивание мышью — обзор, **E** — разговор / сесть / встать / предмет, **V** — камера, **F / T / пробел** — танец, **Esc** — меню / закрыть диалог. Движение останавливает танец. Танцевать нужно на светящихся плитках возле DJ.

## Проверки

```sh
npm test
npx playwright install --with-deps chromium webkit
npm run test:browser
```

`npm test`: Vitest для экономики, миграции, заданий, дружбы, передвижения и посадки; TypeScript и Vite; три проверки URL/MIME production-ресурсов. Браузерные тесты запускают настоящий WebGL, обе ориентации мобильного экрана, ошибки загрузки, покупки и миграцию в production, все десять исходных сидений и два задания Зипа. Новый сценарий проверяет обе сюжетные ветки, все девять локаций с подходами к NPC/сиденьям/выходам и семь новых поручений через dev-инструмент тестирования. Выбор всех героев, аксессуаров и настроек дополнительно проверяется в production. Дополнительный `test:visual` проверяет пиксели всех девяти окружений, 23 NPC и пяти моделей героя, реальные диалоги и отказ загрузки. Его HTML/PNG/JSON находятся в test-results/world-visual/. Доступ к изменению сцены существует только в dev при явном тестовом флаге. Production предоставляет только снимок состояния для диагностики.

CI запускает Chromium и WebKit. Локально один движок: `SPACEBAR_BROWSERS=chromium npm run test:browser`. Скриншоты и JSON-отчёты: `test-results/`, в Actions — артефакт `mobile-launch-tests`. Проверка WebKit на Linux не заменяет проверку физического iPhone; FPS на устройствах не измерен.

## GitHub Pages и архив

`vite.config.ts` задаёт `base: '/Space-bar-rpg/'`, цель Safari 15.4+. В **Settings → Pages → Source** выберите **GitHub Actions**. Workflow `.github/workflows/deploy.yml` проверяет PR; публикует `dist` только из main после объединения. Владельцу нужно проверить зелёные проверки PR, протестировать предпросмотр и самостоятельно подтвердить merge. Код этой ветки не объединяется автоматически.

ZIP исходников и сборки публикуется в GitHub Releases как предварительный выпуск [**0.21.0 · world fixes**](https://github.com/64zszfrgmd-afk/Space-bar-rpg/releases/tag/v0.21.1-preview.1). Для выпуска архива: Actions → Test and deploy GitHub Pages → Run workflow → ветка `feature/v0.21-world-fixes` → `publish_preview` = true. Сначала проходят все проверки; отдельное задание с `contents: write` загружает ZIP и публикует prerelease. Этот запуск не публикует Pages и не выполняет merge. Обычный PR не получает права записи релиза.

В архив входят исходники, lockfile, документация, тесты и `dist`; node_modules, кеш и сохранения пользователей не включаются. Список файлов, исходный коммит и хеши находятся в RELEASE-MANIFEST.json; SHA-256 ZIP прилагается к выпуску. Для повторной упаковки: `npm run build`, затем `python3 scripts/package-release.py` из чистого закоммиченного checkout. ZIP не устанавливается как приложение на iPhone: игра открывается по HTTPS.

## Ограничения

Одиночная игра, девять интерьеров, три планеты, 23 NPC, десять заданий. Переходы между интерьерами выполняются картой: свободного полёта и наземного мира нет. Мультиплеер и свободное ИИ-общение из ТЗ были планами; работающая сеть не имитируется NPC. Точная копия прежнего отсутствующего архива, его неподтверждённые названия и количество контента не заявляются. Сохранения привязаны к браузеру и адресу сайта, не синхронизируются. Требуются WebGL 2 и современный браузер; работа на физическом iPhone и конкретная частота кадров не подтверждены. Версия 0.30 не разрабатывалась.
