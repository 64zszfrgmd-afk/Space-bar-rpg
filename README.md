# Бар на краю Вселенной · Space Bar RPG

Первая играбельная браузерная версия бара «Пьяная туманность» на Three.js, TypeScript и Vite. Все модели, освещение, звёзды и музыка создаются кодом: внешние ассеты и сервер не нужны.

**Статус исходников:** в доступной ветке `work` находится пакет `0.1.0` с четырьмя NPC. Архив ранее созданной версии `0.20` в этот репозиторий не загружен. Исправления публикации не переименовывают этот прототип в 0.20 и не добавляют версию 0.30. Для публикации именно 0.20 сначала нужно восстановить её исходники в ветке PR и повторить проверки. Подробности — [диагностика запуска](docs/IPHONE-PAGES.md).

## Локальный запуск

Нужен Node.js 22.12+ (проверено также на 24).

```sh
npm ci
npm run dev
```

Vite показывает адрес с подпапкой **`/Space-bar-rpg/`**. Проверка production-сборки: `npm run build`. Для её локального просмотра: `npm run preview`, затем `http://localhost:4173/Space-bar-rpg/`. Результат находится в `dist/`. `.npmrc` хранит кеш внутри проекта для совместимости с облачной средой; кеш исключён из Git.

`localhost` на iPhone указывает на сам телефон. Он не открывает Vite, запущенный в Codex Cloud. Предпросмотр Cloud временный и зависит от работающей среды; постоянная игровая ссылка появится после публикации GitHub Pages.

## Как играть

- ПК: WASD / стрелки — ходьба, перетаскивание мышью — обзор, V — камера, E — разговор, T — танец.
- iPhone / Android: джойстик слева — движение, свайп по сцене — обзор. Кнопки справа переключают камеру, танец и музыку.
- Подойдите к бармену за стойкой или к одному из трёх гостей. Появится кнопка разговора. За стойку заходить не нужно.
- Знакомство повышает настроение. У бармена четыре напитка: от бесплатной воды до «Сверхновой». Вода снижает опьянение, оно также постепенно проходит само.
- Танцуйте на светящихся плитках возле DJ: настроение будет расти. Движение останавливает танец.
- Начальный баланс — 120 кредитов. Покупки, показатели и знакомства автоматически сохраняются в localStorage этого браузера. Для нового прохождения очистите данные сайта. Синхронизации между устройствами нет.
- Музыка включается отдельной кнопкой: мобильные браузеры требуют жест пользователя для звука.

## Постоянная HTTPS-ссылка и действия с iPhone

1. Восстановите исходники версии 0.20 в ветке PR. Снимите Draft и объедините PR с `main` только после проверки нужной версии и зелёного задания `build`. Этот PR включает код из прежней ветки `work`, поэтому отдельно объединять первоначальный PR №1 не требуется.
2. В GitHub откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
3. После объединения автоматически запустится **Actions → Test and deploy GitHub Pages**. Для повторного запуска откройте этот workflow → **Run workflow** → `main` → **Run workflow**.
4. После успешного задания `deploy` сайт появится по адресу `https://64zszfrgmd-afk.github.io/Space-bar-rpg/`. При необходимости используйте адрес из Settings → Pages.
5. Откройте HTTPS-адрес в Safari на iPhone. Можно выбрать «Поделиться → На экран Домой». Установка приложения не требуется; для загрузки нужен интернет.

Путь **`/Space-bar-rpg/`** задан в `vite.config.ts` и одинаков для локальной сборки, предпросмотра и Actions. Регистр имени важен. При переименовании репозитория обновите `base` и проверки. Three.js включён в локальный JS-бандл; скрипты и CSS загружаются из `/Space-bar-rpg/assets/`, без CDN.

Workflow проверяет pull request и push в `main`, устанавливает браузеры, запускает тесты, загружает `dist` и публикует его официальными `actions/configure-pages`, `actions/upload-pages-artifact`, `actions/deploy-pages`. Pull request не публикуется в production. При каждом успешном push в `main` ссылка остаётся прежней. Снимки и отчёт доступны в артефакте `mobile-launch-tests`.

Репозиторий приватный. Pages для приватного репозитория зависит от тарифа GitHub; если Settings → Pages предлагает обновить тариф, нужен подходящий тариф либо отдельное решение о публичности репозитория. Эти настройки и видимость автоматически не менялись. Подключение Codex получает HTTP 403 от Pages API, поэтому включить Pages нужно владельцу в интерфейсе GitHub. До успешного `deploy` ссылка может возвращать 404.

## Проверки

```sh
npm ci
npm test
npx playwright install --with-deps chromium webkit
npm run test:browser
```

`npm test` выполняет TypeScript/Vite-сборку и три проверки production-артефактов. Браузерные тесты обслуживают `dist` строго из `/Space-bar-rpg/`, без SPA fallback, и проверяют статусы/MIME JS и CSS, настоящий первый 3D-кадр, мобильные кнопки, портрет/альбом, отсутствие прокрутки, сообщения при недоступном скрипте и WebGL 2. По умолчанию запускаются Chromium и WebKit; для локальной проверки одного движка допустимо `SPACEBAR_BROWSERS=chromium npm run test:browser`. CI запускает оба.

WebKit в Linux — проверка браузерного движка, которая не заменяет физический iPhone. Фактические результаты и ограничения фиксируются в [отчёте](docs/IPHONE-PAGES.md). Готовые файлы из `dist` нужно размещать по HTTP(S); исходный `index.html` и ZIP-предпросмотр в «Файлах» не запускают TypeScript-проект.

## Границы первой версии

Одиночная игра, процедурная мультяшная графика, простые диалоги и фиксированный начальный бюджет. Нет сервера, мультиплеера и реальных платежей. WebGL обязателен. Мобильная проверка в Chromium с эмуляцией touch не заменяет проверку на физическом iPhone в Safari.
